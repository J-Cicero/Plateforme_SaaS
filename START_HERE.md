## 📖 Structure de CHAQUE fichier

Chaque fichier suit le même format:

```
🎯 OBJECTIF
├─ Qu'on veut atteindre

📝 CE QUE TU DOIS FAIRE
├─ Exactement ce qu'il faut faire
├─ Aucun code (juste des indications)
├─ Quelles classes créer
├─ Quels attributs ajouter
└─ Dans quel package

📦 DÉPENDANCES
├─ Ce qu'il te faut avant de commencer
├─ Ajouts au build.gradle
└─ Configurations

🔧 CE À MODIFIER
├─ Fichiers existants à changer
├─ Quelles méthodes ajouter
└─ Où les ajouter

✅ CRITÈRES DE SUCCÈS
└─ Comment savoir que tu as fini

⚠️ IMPORTANT AVANT PROCHAINE ÉTAPE
└─ À tester avant de continuer
```

## 📋 Pour chaque étape

### AVANT de commencer:
1. Ouvre le fichier ETAPE_X.md
2. Lis la section "DÉPENDANCES"
3. Installe/ajoute ce qui manque à build.gradle

### PENDANT:
4. Suis exactly les pas dans "CE QUE TU DOIS FAIRE"
5. Crée les classes, ajoute les attributs
6. Modifie les fichiers indiqués

### APRÈS:
7. Teste selon les "CRITÈRES DE SUCCÈS"
8. Lis "IMPORTANT AVANT PROCHAINE"
9. Passe à l'étape suivante
